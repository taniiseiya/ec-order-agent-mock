# EC受注処理自動化エージェント - 複数モール統合 Mock

ユーザー確認用の静的モックです。Amazon、楽天、Yahoo、Shopifyを横断した受注処理画面を想定しています。

デザインはデジタル庁「ダッシュボードデザインの実践ガイドブックとデザインテンプレート」を参考に、提示型ダッシュボードとして再構成しています。

- 左上から全体指標、右下へ詳細という情報階層
- 8px単位の余白とグリッドに沿ったパネル配置
- グラフ色数を絞った青系カラーパレット
- 装飾よりも数値・比較・要対応の発見しやすさを優先
- 日本のEC運用者向けの日本語文言
- AI受付スタッフ画面は5枚のフレーム画像、応答アニメーション、ブラウザ読み上げ、固定デモ応答のみで構成

## 開き方

ローカル確認用サーバー:

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory ec-order-agent-mock
```

ブラウザで以下を開きます。

```text
http://127.0.0.1:8765/
```

## セキュリティ前提

- 外部API呼び出しはありません。
- 外部フォント/CDN読み込みはありません。
- APIキー、ログインフォーム、`.env`、Cookie保存はありません。
- データは `index.html` 内の固定デモデータのみです。
- AI受付の読み上げはブラウザ標準の `SpeechSynthesis` を使います。ChatGPT/Codex CLIやOpenAI APIには接続していません。
- 受付スタッフ画像は `assets/receptionist/` 配下のローカルアセットです。
- 応答中は `staff-mouth-small.png` と `staff-mouth-open.png` を切り替えて話しているように見せます。
- CSPで `connect-src 'none'` を設定し、ブラウザからのネットワーク通信を禁止しています。
- ローカル確認サーバーを使う場合は `127.0.0.1` に限定してください。
